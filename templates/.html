Project summary

Welcome to my Computer Science Internal Assessment project. This web-based system has been designed to assist the IT department in efficiently tracking and managing the allocation of mobile phones across our school's three campuses. The platform enables administrators to view which devices are currently signed out, who is using them, and which users still require a phone.

By streamlining the approval process for phone requests and providing a centralized dashboard for monitoring device availability, this tool helps reduce administrative workload and ensures accountability. It also maintains a usage history, making it easy to track past check-ins, check-outs, approvals and denials. It also allows for people requesting phones to be notified more quickly as once approved it automaticaly sends and email. The goal of this project is to create a practical, user-friendly solution that addresses real-world challenges faced by the IT department, while demonstrating the application of database management, web development, and user interface design within a school environment.
